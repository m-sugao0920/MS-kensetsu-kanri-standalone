# MS建設管理 デモ版（62工事）

GitHub Pagesで公開し、URLをブラウザーで開いて試すための版です。利用者によるPythonのインストールやサーバー起動は不要です。

## 利用方法

公開URLをChromeまたはEdgeで開いてください。初回は実行環境の読み込みに時間がかかります。インターネット接続が必要です。index.htmlを直接ダブルクリックする方式ではありません。

62工事のデモを用意しています。名前・住所・連絡先などは公開用に置換・削除しています。工事・予算・発注・請求・日報などの流れを試せます。

## 保存

入力した内容は利用者自身のブラウザーに保存します。ブラウザー・端末が違えばデータは別です。PC1・PC2共有用の本番版とは接続しません。ブラウザーのデータ削除や保存容量不足に備え「システム・データ設定」でバックアップを書き出してください。添付PDFは業務データのJSONバックアップには含まれません。実際の業務データは入力せずデモとしてお使いください。

## GitHub Pagesへの配置

このフォルダーの内容をリポジトリの公開対象に置き、GitHub Pagesの公開元をその場所に設定してください。.nojekyllも含めます。データベース、Pythonの実行ファイル、本番バックアップはアップロードしません。公開操作は所有者による確認後に行います。

## 実行環境

Pythonの処理はブラウザー内のPyodide 0.29.3で動作します。実行環境はjsDelivrから取得します。業務データの保存先はブラウザーです。

Pyodide: https://pyodide.org/ （Mozilla Public License 2.0。依存するPython等は各ライセンスに従います。）

## 検証

62工事の原価集計を元の計算処理と比較しました。請求保存・確認、重複防止、更新競合、バックアップ復元を検証しました。公開URL上での最終動作確認は公開準備時に実施します。
